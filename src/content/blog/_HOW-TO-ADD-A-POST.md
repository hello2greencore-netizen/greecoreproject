How to add a blog post
======================

1. Make a new file in this folder named with the post's web address, like
   `heat-pump-rebates-marin.md`. That becomes greencorehvac.com/blog/heat-pump-rebates-marin
2. Copy the block between the --- lines from an existing post to the top and fill it in:
   title, description (one sentence), date (YYYY-MM-DD), category, image, imageAlt,
   and related (service page slugs, separated by commas).
3. Write the post below it. Formatting:
   - `## Heading` and `### Smaller heading`
   - `- item` for bullet lists, `1. item` for numbered lists
   - `**bold**`, `*italic*`, `[link text](/services/heat-pumps)`
   - Tables with | pipes |, like the existing posts
4. Leave a blank line between paragraphs, lists, and headings.

Files starting with an underscore (like this one) are not published.
The blog list, sitemap, and Google article data update automatically.
